# Lolly - Creator Relationship Management & ROI

A high-performance, responsive landing page for **Lolly**, a Creator Relationship Management and ROI tracking platform for influencer and affiliate marketing teams. Built with semantic HTML5, Tailwind CSS, CSS, and Vanilla JavaScript.

## File Details

### Core Files

- [`index.html`]: The primary entry point. Contains semantic HTML structure for sections like Hero, Why It Matters, How It Works, Meet Ana, Built for Teams, and CTAs.
- [`Architectural.md`]: Architectural specifications and coding conventions for building lightweight, bundler-free static web apps.
- [`projects.md`]: Design system tokens, color palette references, section copy, page metadata, and SEO keyphrase guidelines.

### Asset Directory (`assets/`)

- [`assets/css/styles.css`]: Primary stylesheet with Tailwind classes and custom CSS.
- [`assets/js/main.js`]: Handles UI interactions (mobile navigation toggle, sliders, tab navigation, interactive demos).
- **`assets/images/`**: Contains static visual assets (avatars, icons, section diagrams).

---

## Getting Started

Since this is a lightweight static site with no complex build steps required:

1. Open [`index.html`] directly in any web browser, or
2. Serve locally using a local development server like VS Code Live Server.
